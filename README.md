# Gab Webfolio

This repository is a Git backup for one of my personal website / webfolio.

Live site here: https://gab-webfolio.pages.dev/

I use this repo for version control, backup, and tracking changes as I continue improving the website over time.

## About

Gab Webfolio is a personal link-in-bio / portfolio-style website built with HTML, CSS, and JavaScript.

This project contains the main front-end files of the website, including HTML, CSS, JavaScript, images, favicons, and reference files used for development.

## Purpose

This repository is mainly used for:

- Backing up my website files
- Keeping a version history of the project
- Saving reference code for future updates

## Usage

You are welcome to view this project for reference or inspiration.

However, please do not copy, reupload, or reuse the full website as your own. The design, written content, images, branding, and overall structure are part of my personal webfolio.

If you want to use any part of this project, please ask for permission first.
